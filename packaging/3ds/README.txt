Wing Commander for Nintendo 3DS
===============================

This is a homebrew build of the wc1-re SDL2 port. It needs a 3DS with the
Homebrew Launcher, and your own copy of Wing Commander: the Kilrathi Saga
release or the original DOS game. No game data is included.

Installing
----------

1. Copy the "3ds" folder from this archive to the root of the SD card.
   This puts wc1.3dsx at sdmc:/3ds/wc1/wc1.3dsx.
2. Copy the game's files into sdmc:/3ds/wc1/ as well, so that the folder
   sdmc:/3ds/wc1/GAMEDAT exists. Kilrathi Saga also needs its STREAMS folder
   next to GAMEDAT.
3. Start "Wing Commander" from the Homebrew Launcher.

Sound needs sdmc:/3ds/dspfirm.cdc, which the DSP1 homebrew creates. Without
it the game runs silently.

Controls
--------

  Circle Pad      Fly (pitch and yaw); move the pointer in menus
  C-stick         Roll and throttle (New 3DS)
  A               Fire guns; click in menus
  B               Fire missile
  X (hold)        Afterburner
  Y               Cycle target; "Yes" at Y/N prompts
  L / R           Cycle guns / missiles
  ZL / ZR         Navigation map / autopilot (New 3DS)
  D-pad Up/Down   Full speed / stop
  D-pad Left      Communications
  D-pad Right     Lock target
  START           Pause
  SELECT          Esc

The touch screen shows the game picture: tap it to click there, and hold L
while tapping to right-click. Below the picture are keys for ESC, the nav
map (NAV), autopilot (AUTO), communications (COMM), and the cockpit views
F1-F4.

A New 3DS is recommended. The original 3DS runs space combat more slowly.
